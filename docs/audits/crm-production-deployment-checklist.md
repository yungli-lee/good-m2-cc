# CRM Production Deployment 人工查核清單

請從 Cloudflare Pages Production deployment 詳細頁提供：

- Project name
- Environment（必須是 Production）
- Branch（通常為 main）
- Production URL
- Deployment ID
- Deployment time（開始／完成）
- Git commit SHA
- Build status
- Build log 關鍵摘要（warning、error、runtime、migration 相關訊息）

截圖應包含 project header、deployment summary、commit SHA、build log 末段；請遮蔽 API token、環境變數、Secrets 與客戶資料。Production deployed commit 不得以 origin/main 推定。
