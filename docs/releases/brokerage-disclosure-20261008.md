# 經紀業廣告揭露改善 — 2026-10-08

首頁 HomeFooter 與公開路由 SiteFooter 使用共用 BrokerageDisclosure，明示經紀業法定名稱、加盟店名稱、經紀業許可文號及不動產經紀人證號。物件摘要在價格下方直接顯示經紀業及加盟店身分，桌機與手機使用同一資料來源。

揭露沿用公司設定與既有空值 fallback；未新增資料庫欄位或變更權限。經紀人姓名尚未確認，未將阿勇或吳小姐推定為該證號持有人。

手機字號採分行顯示，文字可換行，頁尾預留固定聯絡按鈕所需空間。聯絡頁與物件公司資訊採「經紀業許可文號」標籤。

法規依據：不動產經紀業管理條例第21條要求廣告與事實相符並註明經紀業名稱；內政部98年10月26日內授中辦地字第0980725218號函要求加盟經營另標示加盟身分，不得僅以加盟店名稱替代經紀業名稱。許可文號及經紀人證號為額外資訊，不能取代經紀業名稱；本次 UI 改善不代表逐件廣告內容、委託契約及圖片已完成法律審核。
