# 阿勇阿美角色引導：第一、二階段

## 行為

- 成交／下架物件維持原因與推薦清單，新增透明背景 Q 版双人招呼圖及對話。
- 在售詳情頁提供小角色入口和頁內重開按鈕。介紹面板可關閉，入口可隱藏（本分頁工作階段記憶），不自動開啟或播放聲音。
- 可切換阿勇／阿美及重點、面積格局、推薦特色；解說由每次請求的公開資料整理。客戶端只取得解說及相關物件標題／slug，未传完整物件資料。
- 提供現有相關在售物件與 LINE／更多物件連結，LINE 點擊沿用轉換追蹤及 character-guide 位置標記。
- 支援裝置語音時可手動朗讀。使用 zh-TW 優先裝置聲音，兩角色並非本人錄音或複製聲音。關閉、切換內容、離開或分頁隱藏時停止語音；失敗顯示文字提示。
- 預設阿美，兩角色分開選擇聲音；阿勇僅自動選用可辨識男聲，缺少男聲時提示並可手動指定。裝置有自然語音時優先選用，可分別切換中文聲音，並改善格局與條列斷句。裝置語音品質仍受作業系統／瀏覽器限制，未接上雲端 AI 語音服務。
- 素材為本次 imagegen 依核准雙人人像生成，WebP 保留透明度，720×665，72,852 bytes。品牌 logo 未修改。

## 驗證

- typecheck、lint、Next build 通過。

- 手機詳情順序與公開文案回歸通過。
- Preview 上確認在售頁入口、角色／主題切換、關閉、隱藏與頁內重開；成交頁正常顯示双人圖、原因與在售／知識推薦。
- 測試瀏覽器無可播放的裝置語音，錯誤提示與文字備援已確認；實際手機／桌面裝置語音仍需使用者試聽。
